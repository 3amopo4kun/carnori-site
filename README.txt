CARNORI — временная страница «Скоро запуск»

Файлы:
- index.html      — сама страница
- styles.css      — дизайн и анимации
- script.js       — плавное появление элементов
- favicon.svg     — иконка вкладки
- robots.txt      — разрешает индексацию сайта
- sitemap.xml     — карта сайта

Как опубликовать:
1. Откройте хостинг, к которому будет привязан carnori.ru.
2. Найдите корневую папку сайта. Обычно она называется public_html, www, htdocs или корень сайта в файловом менеджере.
3. Загрузите туда ВСЕ файлы из этой папки.
4. Убедитесь, что index.html лежит именно в корне сайта.
5. Подключите SSL/HTTPS для carnori.ru.
6. Проверьте https://carnori.ru

Главный домен:
- carnori.ru — основной.
- carnori.com — позже настроить 301-редирект на https://carnori.ru

Примечание:
Страница полностью адаптивная и не требует CMS, базы данных или сборщика.
